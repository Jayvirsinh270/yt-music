# Screenshots & Social Preview Checklist

Adding crisp screenshots and a short demo GIF is the fastest way to turn repository visitors into stars.

## 1. Recommended Captures

Save the following files inside `docs/screenshots/`:

| File | What to Capture | Suggested Size |
|---|---|---|
| `hero-player.png` (or `.gif`) | Main desktop player with an atmospheric theme (e.g., *Sunset Sakura* or *Lo-Fi Cozy*) + active queue | `1440x900` |
| `cinema-lyrics.png` | Fullscreen Cinema Mode with Vinyl/Retro Cassette visualizer and synchronized karaoke lyrics | `1440x900` |
| `vibe-compass.png` | 2D Vibe Compass, Circadian mood chips, or Weekly Sound Rewind view | `1440x900` |
| `mobile-app.png` | Flutter Android companion app screenshot | `1080x2400` (or cropped frame) |
| `social-preview.png` | Custom GitHub repository Social Preview card (upload in **Settings → General → Social preview**) | `1280x640` |

## 2. Enable in README.md

Once those files exist in `docs/screenshots/`, open `README.md` under `## 📸 Screenshots & Demo`, remove the `<!--` and `-->` comment tags around the showcase block (and remove the setup tip line), then commit and push.
